# Розрахунок місячного бюджету для Мілстоуна 2 (2 шарди + координатор)

**Регіон:** `eu-north-1` (Stockholm)  
**Тривалість місяця:** 730 годин (30.4 днів, робота 24/7).  
**Архітектура Мілстоуна 2:** 1 вузол-координатор (у публічній підмережі) + 2 вузли-шарди (у приватній підмережі).

---

## Варіант А: Окремі EC2-інстанси для кожного вузла (On-Demand, без Free Tier)

| Компонент | Конфігурація | Кількість | Орієнтовна ціна в `eu-north-1` | Вартість / міс |
|---|---|---|---|---|
| **Координатор (EC2)** | `t3.micro` (2 vCPU, 1 GB RAM) | 1 × 730 год | ~\$0.011 / год | ~\$8.03 |
| **Шарди (EC2)** | `t3.micro` (2 vCPU, 1 GB RAM) | 2 × 730 год | ~\$0.011 / год × 2 | ~\$16.06 |
| **Диски (EBS gp3)** | 8 GB SSD на кожен вузол | 3 × 8 GB = 24 GB | ~\$0.088 / GB-міс | ~\$2.11 |
| **Міжазонний трафік** | Координатор ↔ Шарди (різні AZ) | ~5 GB (вхід+вихід) | \$0.01 / GB у кожен бік | ~\$0.10 |
| **Публічний IPv4** | Для координатора (1 шт.) | 1 × 730 год | \$0.005 / год | ~\$3.65 |
| **Вихідний трафік в інтернет** | API відповіді клієнтам | < 10 GB | перші 100 GB безкошт. (Free Tier) / \$0.09/GB | \$0.00 – \$0.90 |
| **Разом (On-Demand 24/7)** | | | | **~\$30.00 / міс** |

> **Примітка:** якщо додатково додати **NAT Gateway** для виходу приватних шардів в інтернет (наприклад, для `apt`/`docker pull`), це додасть ще **~\$35/міс** (~\$0.048/год + трафік), тому для навчального кластера краще обходитися без NAT Gateway (або ставити пакети через VPC Endpoint / тимчасовий публічний IP / деплой у Docker Compose на 1 інстансі).

---

## Варіант Б: З урахуванням Free Tier / Кредитів (\$200) або 1 EC2 з Docker Compose

1. **Free Tier ліміт EC2:** 750 год/міс `t3.micro` + 30 GB EBS + 750 год публічного IPv4 на 1 інстанс.
   - Якщо розгорнути **координатор + 2 шарди в Docker Compose на 1 інстансі `t3.micro`**, весь місяць 24/7 вкладається у Free Tier (**\$0.00 / міс**).
   - Якщо підняти **3 окремі `t3.micro`** і вмикати їх лише на час тестування та захисту (наприклад, по 50 год/міс кожен = 150 год сумарно < 750 год), вартість теж буде близькою до **\$0.00** (лише ~\$3–\$5 за 24 GB EBS / додаткові публічні IP або покриється стартовими кредитами \$200).
2. **Локальний запуск у Docker Compose** (дозволено умовами для Мілстоунів 2–4): **\$0.00 / міс**.

## Висновок для захисту
- **Повний продакшен-подібний варіант (3 окремі `t3.micro` у двох AZ, 24/7, без Free Tier):** **~\$30/міс** (з NAT Gateway було б ~\$65/міс).
- **Оптимальний навчальний варіант (Free Tier / кредити або зупинка інстансів після тестів):** **\$0 – \$5 / міс** (повністю покривається стартовими кредитами \$200).

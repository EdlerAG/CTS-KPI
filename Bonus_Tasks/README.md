## 1. API Throttling (+5 балів) — [1_api_throttling](file:///D:/Потрібне/5%20курс/ХТС/Bonus_Tasks/1_api_throttling)
- **Серверний ліміт (`server.py`, порт `8001`):** 5 запитів/хв на клієнта, понад квоту — `HTTP 429 Too Many Requests` із заголовком `Retry-After`.
- **Клієнтська черга (`client_queue.py`):** `ThrottledClient` обмежує власну частоту до 4 запитів/хв і ставить зайві запити в `asyncio.Queue`, щоб ніколи не отримувати `429`.
- **4 алгоритми в `limiters.py`:**
  1. **Fixed Window** — простий лічильник на фіксований інтервал (ризик подвійного сплеску на межі хвилини).
  2. **Sliding Window Log** — точні мітки часу в черзі за останні 60 с (без крайового ефекту, але більше RAM при мільйонах запитів).
  3. **Token Bucket** — відро наповнюється з постійною швидкістю, дозволяє контрольовані короткі сплески (*burst*) до розміру ємності.
  4. **Leaking Bucket** — черга з постійною швидкістю виходу; ідеально згладжує трафік до рівномірного потоку.

**Запуск:**
```powershell
cd "D:\Потрібне\5 курс\ХТС\Bonus_Tasks\1_api_throttling"
..\..\.venv\Scripts\uvicorn.exe server:app --port 8001
# В іншому вікні:
..\..\.venv\Scripts\python.exe client_queue.py
```

## 2. Кешуючий шар (+5 балів) — [2_caching_layer](file:///D:/Потрібне/5%20курс/ХТС/Bonus_Tasks/2_caching_layer)
- **Реалізація (`server.py` на порту `8002`, `cache.py`):** LRU + TTL кеш перед координатором для `READ` та `EXISTS` (заголовки `X-Cache: HIT/MISS`, статистика `/cache/stats`) з автоматичною **інвалідацією партиції** на `CREATE` та `DELETE`.
- **Коли кеш дає виграш:** read-heavy навантаження з локальністю («гарячі ключі» `hot keys`) — дані віддаються з памʼяті за ~1–2 мс без кворумного опитування реплік.
- **Коли кеш робить гірше:**
  1. 100% унікальні ключі (`0%` hit rate) — кеш додає зайвий мережевий стрибок (proxy hop), серіалізацію та витрату RAM без жодного прискорення;
  2. write-heavy навантаження — постійні інвалідації зводять hit rate до нуля;
  3. без інвалідації (лише TTL) — ризик віддавати застарілі дані (*stale reads*) всупереч кворумам $R + W > N$;
  4. *cache stampede* при одночасному протуханні популярного ключа.

**Запуск (при запущеному кластері Лаби 4 на порту `8000`):**
```powershell
cd "D:\Потрібне\5 курс\ХТС\Bonus_Tasks\2_caching_layer"
..\..\.venv\Scripts\uvicorn.exe server:app --port 8002
# В іншому вікні:
..\..\.venv\Scripts\python.exe benchmark_cache.py
```

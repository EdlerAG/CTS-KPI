1. БОНУС 1 — API THROTTLING (+5 балів)
--------------------------------------------------------------------
Запусти проксі (ліміт сервера 5 req/min -> 429):
  cd "D:\Потрібне\5 курс\ХТС\Bonus_Tasks\1_api_throttling"
  ..\..\.venv\Scripts\uvicorn.exe server:app --port 8001

У другому вікні покажи перевищення квоти (перші 5 -> 200, 6-й і 7-й -> 429):
  ..\..\.venv\Scripts\python.exe client_queue.py

Що пояснити викладачу:
  - Серверний middleware у `server.py` (5 req/min -> HTTP 429 + Retry-After).
  - Клієнтський `ThrottledClient` у `client_queue.py` (4 req/min через `asyncio.Queue`).
  - Різниця 4 алгоритмів у `limiters.py`: Fixed Window (простий, але сплески на межі хвилини), Sliding Window (точний за останні 60 с), Token Bucket (дозволяє burst до ємності), Leaking Bucket (рівномірне згладжування потоку).


2. БОНУС 2 — КЕШУЮЧИЙ ШАР (+5 балів)
--------------------------------------------------------------------
Запусти кешуючий проксі (порт 8002 перед координатором 8000):
  cd "D:\Потрібне\5 курс\ХТС\Bonus_Tasks\2_caching_layer"
  ..\..\.venv\Scripts\uvicorn.exe server:app --port 8002

У другому вікні прожени бенчмарк (гарячі ключі vs 100% miss):
  ..\..\.venv\Scripts\python.exe benchmark_cache.py

Покажи також статистику та інвалідацію:
  Invoke-RestMethod http://localhost:8002/cache/stats

Що пояснити викладачу:
  - Заголовки `X-Cache: HIT / MISS`, TTL + автоматична інвалідація `invalidate_partition` при POST/DELETE.
  - Коли кеш погіршує: 0% hit-rate на унікальних ключах (зайвий proxy hop + RAM), write-heavy (часті інвалідації), stale reads без інвалідації.
